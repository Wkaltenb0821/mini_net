Mininet project for COMP 312


This project was created around mininet. Our goal was to experiment, find bugs, 
and in the end have a deeper understanding of debugging and how it works. In 
the first stages of this project we got mini-net running on both windows and
apple devices. We knew going into this project that there would be many bugs 
and complications within mininet. The repository is reflects our findings. 

- mac_iOS_mininet_install_guide gives a rundown of how to setup mininet on
  Apple devices by emulating it on a UTM, and creating a VM. 

bug_log 
Is our main bug log, that captures minor bugs found in mininet. Each contains 
a description of the bug, the error message, why the error message occurred and
a fix for it. 

python2-shebang 
This was a more complex bug, that we chose to dedicate an additional file to.
